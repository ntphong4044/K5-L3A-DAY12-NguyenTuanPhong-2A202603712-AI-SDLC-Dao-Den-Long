Bảng xếp hạng

Điểm = tổng điểm các Đêm đã thắng (0–3 Đêm). Giữ top 10; bằng điểm thì ai đạt trước đứng trên. Lưu trên máy này (localStorage) nên vẫn còn sau khi tắt game.

Xuất bảng ra tệp để nộp: npm start -- --export-leaderboard out.json (đọc tệp hồ sơ của lần npm run bench -- --keep-profile gần nhất, hoặc tệp chung .ddl/leaderboard.json).
